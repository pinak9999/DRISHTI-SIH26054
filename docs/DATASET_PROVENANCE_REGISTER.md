# DRISHTI — Dataset Provenance Register (SIH26054)

**Date:** 2026-10-03  
**Purpose:** Document every data source used or considered for DRISHTI, with verified official provenance, licensing, file hashes, and relevance assessment.

> [!IMPORTANT]
> The repository contains:
> 1. **Internal Synthetic Corpus (`DRISHTI-SynthCorpus-v1.0`)** used for the 9-class aero-piston digital twin software demonstrator (`SYNTHETIC-ONLY`).
> 2. **Two Verified Open-Access Experimental ICE Datasets (`LiU-ICE` and `Marine Engine Fault`)** acquired from official university/Zenodo repositories into `data/raw/` for isolated real-data validation of anomaly detection, sensor-fault isolation, and subsystem fault diagnosis. Neither external dataset is a MALE UAV aero-piston dataset; their domain boundaries are strictly preserved.

#### Manual Download & Verification Procedure (LiU-ICE)
Note: On the older 2024 subpage (`index_competition_24.html`), `trainingdata.zip` closes the TLS connection without response, whereas the official DXC25 GitLab archive (`dxc25liu-ice-main.zip`) and the 2027 competition archive (`trainingdata_2027.zip`) respond with `HTTP 200 OK`.

```powershell
curl.exe -sS -L -o "data/raw/liu_ice/dxc25liu-ice-main.zip" "https://gitlab.com/daner29/dxc25liu-ice/-/archive/main/dxc25liu-ice-main.zip"

```
